# Avito datacamp тестовое

Задача: по событиям внутри суточного окна присвоить каждой `cookie_id` score от 0 до 1, где 1 - трафик сервисов автоматизированного сбора данных.

**Метрика:** Precision при Recall ≥ 70% на скрытой тестовой выборке.


## Условия и ограничения

- Запрещено многое, разрешено малое


## Данные


`data/train.csv` - обучающая выборка с target;

`data/test.csv` - тестовая выборка без target;

`data/events.csv.gz` - события для построения признаков;

`sample_submission.csv` - пример файла для отправки решения.


## Предобработка

### Дубликаты
328 905 → 324 042 строк после `drop_duplicates()`. Проверка показала, что доля дублей у ботов и людей одинакова

### Фильтрация по окну наблюдения
Для каждой cookie оставляем только события в `[window_start_ts, window_end_ts)`. Это обязательное условие задачи - признаки должны быть известны на момент конца окна. Фильтруем сразу для train и test вместе, чтобы не потерять события тестовых cookie

### Сортировка по времени
96.5% cookie имеют несортированные события. Без `sort_values(["cookie_id", "event_ts"])` все тайминговые признаки через `diff()` дают бессмысленные (в т.ч. отрицательные) интервалы.


## Признаки

### Тайминги между событиями
Самая сильная группа признаков. Бот с фиксированным ритмом даёт низкий коэффициент вариации интервалов, а человек - хаотичный


### Паттерн событий
Доля каждого типа события от общего числа у cookie - ключевой поведенческий сигнал:
- Скрейпер цен: много `search_results_view`, мало `item_view`
- Скрейпер контактов: много `item_view` + `contact_phone_show`, почти нет поиска

### Мета-данные cookie
`cookie_age_days` (возраст на начало окна) - второй по важности признак. Свежесозданная кука с высокой активностью подозрительна.

### Поиск
Глубина пагинации (`search_mean_page`, `search_max_page`) и разнообразие запросов (`search_query_diversity = nunique / count`). Человек редко уходит дальше 2-3 страниц и формулирует разные запросы. То есть искали то, что если запросы монотонны - бооот

### User-Agent
Явные маркеры ботов в строке user-agent (далее будет как ua): `HeadlessChrome` (26% ботов), `Scrapy` (26%), `curl` (25%), `python-requests` (19%). Несоответствие UA и платформы - признак подделки данных

### Эвристический счётчик
Сумма 6 бинарных правил в один признак `heuristic_score`:
- явный маркер бота в UA
- медианный интервал < 1 сек
- CV интервалов < 0.3
- устаревшая версия Chrome
- несоответствие UA и platform
- доля повторяющихся событий > 80%

Модель использует его как один из входов - правила и ML усиливают друг друга.

## Улучшения

**Baseline** - RandomForest на 2 признаках (`n_events`, `item_nunique`) из quickstart.ipynb. P@R70 ≈ 0.25 на валидации.

**LightGBM + базовые фичи** - добавили тайминги, доли событий, мышь, возраст cookie. P@R70 = 0.64.

**Optuna на одном сплите** - подбор гиперпараметров. P@R70 = 0.79–0.80, но нестабильно: разброс по дням 0.57–0.82 выдал завышенную оценку.

**Multi-day CV + Optuna** - Optuna оптимизирует среднее по последним 3 дням CV. Честная оценка: P@R70 = 0.72 ± 0.10.

**Ансамбль LightGBM + CatBoost** - веса подбираются по CV перебором. Добавлены UA-маркеры ботов, паттерн переходов, item diversity, эвристический счётчик.

## Валидация

**Time-based split:** данные идут подряд по дням (2026-04-06 → 2026-04-19 train, 2026-04-20 test). Случайный split нарушил бы временной порядок - модель бы видела будущее.

**Multi-day CV:** последние 5 дней train используются поочерёдно как валидация. Каждый раз модель обучается на всём, что было до этого дня. Это имитирует реальный сценарий деплоя и даёт оценку устойчивости по дням.

Финальная модель переобучается на всём train - при подобранных гиперпараметрах это стандартная практика для kaggle-подобных задач

## Ограничения

- Валидация нестабильна из-за малого числа ботов в каждом дне (~50–70 штук) - один неверно классифицированный бот сильно меняет метрику
- Модель обучена на трафике конкретных известных сервисов сбора данных. Новые сервисы с другим поведением могут проскользнуть
- Тайминговые признаки - самые сильные, но медленный бот имитирующий человека по скорости останется незамеченным
